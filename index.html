PROJECT 01 / 個人制作・開発中

1vs1対戦ゲームの
マッチングシステム

  • C++
  • Go
  • TCP / UDP
  • Docker

C++によるゲームクライアントと、Goによるゲームサーバーを組み合わせたオンライン対戦ゲームを開発しています。

レート差に基づくマッチング、対戦用Roomの管理、TCP・UDPを使い分けた通信処理を実装しています。

特にサーバー側の設計に重点を置き、対戦相手の決定からゲーム開始、切断時のRoom解散までの一連の処理を構築しました。
